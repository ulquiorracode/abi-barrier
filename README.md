# abi-barrier

[![CI](https://github.com/ulquiorracode/abi-barrier/actions/workflows/ci.yml/badge.svg)](https://github.com/ulquiorracode/abi-barrier/actions/workflows/ci.yml)

[![Rust: 2024](https://img.shields.io/badge/Language-Rust%202024-orange.svg)](https://www.rust-lang.org/)

Zero-cost, unbreakable C-ABI safety boundary and FFI panic isolation meta-framework for high-performance game engines, systems hosts, and plugins (GoldSrc, Quake, Unreal, Shared C-Libraries).

---

## Highlights

- **Unbreakable C-ABI Barrier**: Guarantees zero unwinding panics cross foreign FFI boundaries (`catch_panic_barrier` with landing pad optimization).
- **Strict Closed-World Taxonomy**: Eliminates stringly-typed ABI contracts; all calling conventions and panic reactions are enforced via closed enums (`CallingConvention`, `PanicStrategy`).
- **Anti-Silent Error Suppression (Strict Fail-Fast)**: Zero unlogged ignores. Caught panics and invalid states are formatted and reported immediately before safe fallback return or abort.
- **Scrooge Zero-Waste Sympathy**: Zero allocations on happy paths. Pointer and C-string validations occur directly against raw addresses and CPU registers without heap overhead.
- **Monomorphic SMA Integration**: Native middleware layer (`AbiBarrierLayer`) for Stitch Sewing Machine Architecture (SMA) pipelines with zero dynamic dispatch.
- **Empirical Zero-Cost Overhead**: Verified via Criterion benchmarks (<0.45 ns per call in release mode, identical to raw non-guarded C calls).

## Quick Start

### 1. Declarative Function Barrier (`#[barrier]`)

Protect any C-ABI exported function against panics and invalid arguments:

```rust
use abi_barrier::prelude::*;

#[barrier(
    convention = CallingConvention::C,
    on_panic = PanicStrategy::ReturnError(-1)
)]
pub fn engine_client_command(client_id: i32, cmd_ptr: *const core::ffi::c_char) -> i32 {
    let cmd = unsafe { ensure_valid_c_str(cmd_ptr, "cmd_ptr").unwrap() };
    println!("Executing command `{cmd}` for client #{client_id}");
    0
}
```

If a panic or unexpected failure occurs inside `engine_client_command`, `abi-barrier`:

1. Intercepts the unwinding panic before crossing the C-ABI boundary.
2. Emits diagnostic panic metadata to `stderr`.
3. Returns `-1` to the host engine without crashing or corrupting host state.

---

### 2. Stitch SMA Pipeline Middleware (`AbiBarrierLayer`)

Wrap any U-cycle execution pipeline in GoldSrc or server plugins:

```rust
use abi_barrier::prelude::*;
use stitch_core::pipeline::Pipeline;

let barrier_layer = AbiBarrierLayer::new(
    |ctx: &mut ClientContext, _intent: &CommandIntent| {
        if ctx.edict_ptr.is_null() {
            Err(AbiError::NullPointer { argument: "edict_ptr" })
        } else {
            Ok(())
        }
    },
    |_err, _ctx| -1,
    PanicStrategy::ReturnError(-1),
);

let mut pipeline = Pipeline::on_terminal(CommandExecutionTerminal).wrap(barrier_layer);
```
